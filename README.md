# Lantern Drift

**Play:** [Playgama](https://playgama.ai/play/nvk6egiap5t7kd) · [GitHub Pages](https://arnavjhajharia.github.io/lantern-drift/) · [gameplay video](https://youtu.be/_LqOpMJtgDI)

A small original sliding puzzle for the web. Lanterns drift in a straight line until a stone or another lantern stops them;
lanterns of the same colour always drift together. Bring each one home to the ring of its colour.

- 28 nights, generated by `gen.js` and checked by the BFS solver in `core.js`. Every level is solvable, and its par is the proven minimum number of moves.
- `index.html#selftest` replays every optimal solution through the real input code and reports `SELFTEST 28/28`.
- Sound: CC0 recorded audio files (OpenGameArt music loop by isaiah658 + Kenney chime/bump/click; see audio/CREDITS.txt). The chime is pitched per note with playbackRate. The only image is title.jpg (Higgsfield, GPT Image 2.5). No tracking, no build step.

Made with AI assistance: Claude (code, level generator, solver) and Higgsfield GPT Image 2.5 (title illustration).
